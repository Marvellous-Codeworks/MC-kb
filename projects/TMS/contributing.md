# Contributing to The Marvellous Suspender

TMS is maintained by volunteers and installed in more than 100,000 browsers, so a change has to be small enough to review and tested before it ships.

Three files in the repository say how:

- **[`AGENTS.md`](https://github.com/gioxx/MarvellousSuspender/blob/master/AGENTS.md)**: the rules every change has to meet and what "done" means. One file for people and for coding agents.
- **[`CONTRIBUTING.md`](https://github.com/gioxx/MarvellousSuspender/blob/master/CONTRIBUTING.md)**: setup, branches, commits, how to run the tests.
- **[`SECURITY.md`](https://github.com/gioxx/MarvellousSuspender/blob/master/SECURITY.md)**: how to report a vulnerability in private.

Translations do not go through the repository: use [Crowdin](https://crowdin.com/project/tms).

## If you use AI tools

You can. The person who opens the pull request is its author: you have read it, run the tests, loaded the extension and tried the change, and you can answer a question about any line. Say in the pull request which parts were AI-assisted. A pull request whose author cannot explain it is closed without review.

If you use a coding agent, point it at `AGENTS.md` before it writes anything.
