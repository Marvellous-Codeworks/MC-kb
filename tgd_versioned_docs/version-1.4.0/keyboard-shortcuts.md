# Keyboard shortcuts

TGD ships with two default keyboard shortcuts and four additional commands with no default binding. You can view and reassign all of them in **Options → Keyboard Shortcuts**, or directly at `chrome://extensions/shortcuts`.

---

## Default shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+D` | Discard the active tab |
| `Ctrl+Shift+S` | Suspend the active tab |

---

## Commands without a default binding

These commands are available but require you to assign a shortcut manually:

| Action |
|--------|
| Discard all tabs in the active window |
| Reload all tabs in the active window |
| Discard all tabs in all windows |
| Reload all tabs in all windows |

---

## Changing shortcuts

1. Go to `chrome://extensions/shortcuts`
2. Find **The Great-er Tab Discarder** in the list
3. Click the pencil icon next to a command and press your desired key combination

Chrome requires shortcuts to include at least one modifier key (`Ctrl`, `Alt`, or `Shift`). Shortcuts that conflict with browser or OS shortcuts may not register.
